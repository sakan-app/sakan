# سكن | SAKAN

**منصة دولية للتعارف الجاد والزواج المستقر في أوروبا والعالم العربي.**

سكن ليست تطبيق مواعدة، بل منصة زواج جادة مبنية على ثلاث ركائز: **الثقة، الخصوصية، والتوافق الحقيقي**. الاسم مستوحى من قوله تعالى «لتسكنوا إليها»، والشعار يدمج بين حلقتَي الزواج وسقف البيت ليكوّن شكل قلب.

---

## 1. الهوية البصرية والتصميم

| العنصر | القيمة | الاستخدام |
| --- | --- | --- |
| الأزرق الملكي | `#0D1B3D` | الخلفيات الأساسية، الهيدر، الفوتر، بطاقات الأعضاء |
| الذهبي المطفي | `#D4AF37` | الأزرار، العناوين المميزة، الحدود، الأيقونات |
| الأبيض العاجي | `#FFFFFF` / `#FCFBF8` | الأقسام الفاتحة والنصوص على الخلفيات الداكنة |

**الخطوط:** خط `Cairo` لكل النصوص العربية، وخط `Montserrat` للنصوص اللاتينية والأرقام.

**نظام التصميم:** جميع الألوان والظلال والتدرجات معرّفة كـ Design Tokens في `src/styles.css` بصيغة `oklch`، ولا يوجد أي لون مكتوب يدويًا داخل المكوّنات. هذا يضمن ثبات الهوية البصرية عبر كل الصفحات وسهولة تعديلها من مكان واحد.

**دعم RTL:** الواجهة كاملة مبنية من اليمين إلى اليسار (`dir="rtl"`) مع محاذاة صحيحة للأيقونات والأسهم والحقول.

**التجاوب (Responsive):** تصميم يعمل على الجوال والتابلت وسطح المكتب باستخدام Flexbox و Grid، مع تغيّر جذري في بعض الأقسام (مثل تحوّل شبكة الأعضاء إلى كاروسيل أفقي على الجوال).

## 2. الصفحة الرئيسية (Home)

### قسم البطل (Hero)
- صورة عروسين واقعية بجودة عالية تشغل جانب الشاشة مع تدرّج لوني يندمج مع الخلفية الكحلية.
- عنوان رئيسي: «منصة تجمع القلوب لتبني بيتاً واحداً» مع تمييز ذهبي للجزء الثاني.
- نص فرعي يوضح رسالة المنصة.
- **مؤشرات ثقة فورية:** أكثر من 125 ألف عضو موثّق، 8 آلاف قصة نجاح، 45 دولة حول العالم.

### نموذج البحث الذكي
لوحة بحث مستقلة بخلفية كحلية وحدود ذهبية تحتوي على:
1. **أنا** — اختيار الجنس (رجل / امرأة) بأزرار قابلة للنقر وليس قوائم مملة.
2. **أبحث عن** — جنس الطرف الآخر.
3. **الفئة العمرية** — قائمتان (من / إلى) بمدى من 18 إلى 60 سنة.
4. **مكان الإقامة** — قائمة بكل الدول المتاحة في قاعدة البيانات.
5. زر **«ابدأ رحلتك الآن»** ذهبي متدرج ينقل المستخدم مباشرة لصفحة النتائج مع تمرير كل المعايير في رابط الصفحة (URL Search Params) — أي أن نتيجة البحث قابلة للمشاركة والحفظ.
6. ملاحظة أمان: «آمن وخاص وسريع 100٪».

### شريط الأعضاء النشطين الآن (Live Strip)
شريط حي أسفل البطل يعرض مؤشر **LIVE** نابض، وصور أعضاء نشطين مع الاسم والعمر والمدينة وعلامة التوثيق، وعدّاد «+1253 عضواً نشطاً الآن». الهدف منه إثبات حيوية المنصة لحظة دخول الزائر.

### لماذا سكن؟ (المميزات)
أربع بطاقات بأيقونات ذهبية:
- **بيئة آمنة وموثوقة** — حماية صارمة وقوانين أوروبية (GDPR) تضمن الخصوصية.
- **حسابات حقيقية 100٪** — نظام تحقق صارم من الهوية والصور لمنع الحسابات الوهمية.
- **ذكاء اصطناعي للمطابقة** — خوارزميات تقترح شريك الحياة بناءً على توافق الشخصيات.
- **تواصل بلا حدود** — ترجمة فورية للرسائل داخل الشات لكسر حاجز اللغات الأربع.

### أعضاء نشطون بالقرب منك
شبكة بطاقات أعضاء (4 أعمدة على سطح المكتب) بنفس مكوّن البطاقة المستخدم في صفحة النتائج.

### قصص النجاح
قسم يعرض أزواجًا تعرّفوا عبر المنصة مع اقتباس قصير ومكان الزواج، لتعزيز الثقة الاجتماعية.

---

## 3. صفحة نتائج البحث (Search Results)

- عنوان **«أعضاء نشطون بالقرب منك»** مع ملخص لمعايير البحث المطبّقة على شكل شرائح (Chips): «أبحث عن: امرأة»، «العمر: 18 - 60»، «الإقامة: كل الدول».
- عدّاد نتائج ديناميكي: «تم العثور على X عضواً موثقاً».
- **الفلترة الفعلية** تتم على بيانات الأعضاء حسب الجنس المطلوب والفئة العمرية والدولة.
- **على سطح المكتب:** شبكة بطاقات متعددة الأعمدة.
- **على الجوال:** كاروسيل أفقي قابل للسحب بنعومة (scroll-snap) بدل الشبكة، تمامًا كما في التصميم الأصلي.
- **حالة فارغة:** رسالة واضحة عند عدم وجود نتائج مطابقة مع إمكانية تعديل البحث.

### بطاقة العضو (MemberCard)
مكوّن واحد قابل لإعادة الاستخدام يعرض:
- الصورة الشخصية بنسبة ثابتة.
- **نقطة خضراء** للحالة النشطة.
- **شارة التوثيق الزرقاء** للأعضاء الموثّقين.
- شريط سفلي كحلي يحوي الاسم + العمر بالذهبي، والمدينة والدولة مع علم الدولة.
- تأثير رفع وتوهج ذهبي عند المرور بالمؤشر، والبطاقة كلها رابط لصفحة الملف الشخصي.

---

## 4. صفحة الملف الشخصي (Member Profile)

صفحة ديناميكية بمسار `/member/:id` تعرض:
- **صورة رئيسية كبيرة** مع تراكب متدرج.
- الاسم، العمر، شارة التوثيق، المدينة والدولة مع العلم.
- **النبذة الشخصية (Bio)** المكتوبة بالعربية.
- **معرض الصور (Gallery)** بصور إضافية للعضو.
- **بطاقات معلومات:** الجنسية، ما يبحث عنه، الحالة، اللغة.
- **وسوم الاهتمامات** بشكل شرائح ذهبية.
- زر **«ابدأ المحادثة»** الذهبي البارز كدعوة أساسية للإجراء.
- التنقل عبر رابط رجوع للنتائج، وصفحة 404 مخصصة إذا كان المعرّف غير موجود.

---

## 5. المكوّنات المشتركة

**الهيدر (Header):**
- الشعار الرسمي (قلب/بيت ذهبي) مع كلمة «سكن | SAKAN».
- روابط التنقل: الرئيسية، عن المنصة، قصص نجاح، باقات الاشتراك.
- **مبدّل اللغة** بقائمة منسدلة: العربية، الإنجليزية، الألمانية، الروسية.
- زر «تسجيل الدخول».
- قائمة همبرغر كاملة على الجوال.

**الفوتر (Footer):**
- الشعار ووصف مختصر للمنصة.
- روابط مهمة وروابط قانونية.
- أيقونات التواصل الاجتماعي (فيسبوك، إنستغرام، يوتيوب، تويتر).
- معلومات التواصل وحقوق النشر.

## 6. نموذج البيانات (Data Model)

كل الأعضاء معرّفون محليًا في `src/data/members.ts` بالشكل التالي:

```ts
type Member = {
  id: string;
  name: string;          // الاسم
  age: number;           // العمر
  gender: "male" | "female";
  lookingFor: "male" | "female";
  country: string;       // الدولة
  city: string;          // المدينة
  countryFlag: string;   // علم الدولة
  profilePhoto: string;  // الصورة الرئيسية
  gallery: string[];     // معرض الصور
  isVerified: boolean;   // موثّق
  bio: string;           // النبذة
};
```

القاعدة تحتوي على **12 ملفًا شخصيًا واقعيًا** موزّعين بين أوروبا (ألمانيا، النمسا، فرنسا، سويسرا، التشيك) والعالم العربي، بأسماء وبيانات ونبذات عربية حقيقية.

## 7. التقنيات المستخدمة

- **React 19 + TypeScript** — معمارية مبنية على مكوّنات صغيرة قابلة لإعادة الاستخدام.
- **Vite 7** — أداة البناء وخادم التطوير السريع.
- **TanStack Router** — توجيه معتمد على الملفات مع تمرير معايير البحث عبر الرابط.
- **Tailwind CSS v4** — تنسيق عبر Design Tokens في `src/styles.css`.
- **Lucide Icons** — أيقونات خفيفة ومتناسقة.

### هيكل المشروع

```
src/
├── assets/            الصور (الشعار، صورة البطل، صور الأعضاء)
├── components/
│   ├── Header.tsx     الهيدر ومبدّل اللغة
│   ├── Footer.tsx     الفوتر
│   └── MemberCard.tsx بطاقة العضو
├── data/members.ts    بيانات الأعضاء ودوال الفلترة
├── routes/
│   ├── index.tsx      الصفحة الرئيسية
│   ├── search.tsx     نتائج البحث
│   └── member.$id.tsx الملف الشخصي
└── styles.css         نظام التصميم الكامل
```

## 8. رحلة المستخدم الكاملة

1. يدخل الزائر الصفحة الرئيسية ويرى الرسالة ومؤشرات الثقة فورًا.
2. يملأ نموذج البحث (أنا / أبحث عن / العمر / الدولة) ويضغط «ابدأ رحلتك الآن».
3. ينتقل لصفحة النتائج ويرى الأعضاء المطابقين مع إمكانية تعديل المعايير.
4. يضغط على بطاقة عضو فينتقل لملفه الشخصي ويطّلع على النبذة والمعرض والاهتمامات.
5. يضغط «ابدأ المحادثة» لبدء التواصل.
