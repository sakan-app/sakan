# SAKAN — ملفات قاعدة البيانات الكاملة

هذا المجلد يحتوي كل ما تحتاجه لبناء قاعدة بيانات SAKAN من الصفر.

## طريقة التطبيق

الخيار الأسهل: افتح SQL Editor في مشروعك، والصق محتوى `SAKAN_FULL_DATABASE.sql`
كاملاً ونفّذه مرة واحدة من الأعلى إلى الأسفل.

الخيار البديل (خطوة بخطوة): نفّذ الملفات مرتّبة بالاسم، بدءاً من
`00000000000000_storage_buckets.sql` ثم بقية الملفات بالتسلسل الزمني (48 ملفاً).

## ما كان ناقصاً وأُضيف

| العنصر | الحالة |
|---|---|
| أوعية التخزين الثمانية (avatars, gallery, chat-media, wallpapers, featured, verification, documents, temporary) | كانت غير موجودة في ملفات الترحيل — أضفتها في `00000000000000_storage_buckets.sql` |
| سياسات التخزين لكل وعاء | موجودة ومُراجعة: avatars/gallery/verification/documents/temporary مجمّعة في سياسة واحدة، و chat-media و wallpapers و featured بسياسات خاصة |
| بيانات الباقات (plans) | موجودة داخل الترحيل `20260802181124_...` |
| الامتدادات pg_cron و pg_net | موجودة داخل `20260803121431_...` و `20260803123231_...` |
| نشر Realtime وREPLICA IDENTITY للجداول الحيّة | موجود في ترحيلات المحادثات والإشعارات |

بعد التدقيق: لا يوجد ملف SQL ناقص. الجداول والأنواع والدوال والمحفزات
والصلاحيات وسياسات الأمان كلها مُغطّاة.

## ما لا يمكن إنجازه بـ SQL (يُضبط يدوياً في لوحة المشروع)

1. مزوّد Google للدخول: تفعيله ووضع Client ID / Secret.
2. المفاتيح السرّية للخادم: `STRIPE_SECRET_KEY`، `STRIPE_WEBHOOK_SECRET`،
   مفاتيح VAPID للإشعارات، ورمز `PUSH_DISPATCH_TOKEN`.
3. عناوين إعادة التوجيه المسموحة (Site URL / Redirect URLs) للدخول.
4. جدولة مهام pg_cron تحتاج نفس النطاق العام للمشروع في عنوان الاستدعاء.
